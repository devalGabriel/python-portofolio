# 🧾 Analizator OCR Bonuri Cumpărături

O aplicație Python ce permite încărcarea imaginilor cu bonuri fiscale, extrage datele automat folosind OCR (Tesseract) și le analizează inteligent (AI basic). Oferă export în JSON/CSV și sumar de cumpărături.

---

## 🔧 Tehnologii folosite
- Python 3.9+
- Flask (web UI)
- pytesseract + Tesseract-OCR (motor OCR)
- OpenCV (procesare imagini)
- Pandas (export CSV)
- Regex (parsing text)
- HTML/CSS
